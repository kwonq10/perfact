スキマ Chrome拡張 - プライバシーポリシー

Privacy Policy for Chrome Extension

1. はじめに

本ページは、Chromeのサイドパネルで動作する拡張機能「スキマ」（以下「本拡張機能」）における情報の取り扱いについて説明するプライバシーポリシーです。

Web版「スキマ」（sukimacalendar.com）のプライバシーポリシーとは別に、本拡張機能専用のものとして本ページを設けています。Web版をご利用の場合は、Web版のプライバシーポリシー（/privacy）をご確認ください。

2. 取得する情報

本拡張機能は、ユーザーがGoogleアカウントでログインした際に、Googleカレンダーのカレンダー一覧情報と予定の日時情報のみを取得します。

メールアドレスその他の個人情報を取得することはありません。

3. Googleカレンダーから取得する情報

本拡張機能がGoogle Calendar APIから取得する情報は以下のとおりです。

  • カレンダー一覧：カレンダー名、カレンダーID、アクセス権限（オーナー／編集者／閲覧者）
  • 予定情報：開始日時、終了日時のみ

予定のタイトル、参加者、場所、詳細説明などの情報は、空き時間の計算には利用しません。

4. 情報の利用目的

取得した情報は、ユーザーが指定した期間における空き時間の計算と表示のためだけに利用します。

上記以外の目的には利用しません。

5. 情報の保存

カレンダー情報について：本拡張機能は、取得したカレンダー情報（カレンダー一覧・予定の日時・空き時間の計算結果）を chrome.storage、localStorage、sessionStorage、IndexedDB のいずれにも保存しません。

取得した情報は拡張機能のサイドパネルを表示している間のみ、ブラウザのメモリ上で一時的に扱われ、サイドパネルを閉じるとその内容は破棄されます。

拡張機能自身の設定について：上記とは別に、本拡張機能はスキマのサービスを利用するための情報を、ブラウザの localStorage に保存します。保存するのは次の2種類だけです。

  • スキマとの連携用セッショントークンと、その有効期限
  • スキマのサーバーから取得した設定値（無料利用回数の制限が有効かどうか）と、その取得時刻

これら2種類の情報に、カレンダーの内容は一切含まれません。いずれもお使いのブラウザ内にのみ保存されます。連携用セッショントークンは、本拡張機能のログアウト操作で削除されます。chrome.storage は使用していません。

6. 外部送信

カレンダー情報の送信先は、Google Calendar API（googleapis.com）のみです。カレンダー一覧・予定の日時・空き時間の計算結果を、開発者が運営するサーバーやデータベースへ送信することは一切ありません。

これとは別に、本拡張機能はスキマのサービスを利用するために、開発者が運営する sukimacalendar.com と通信します。この通信に、カレンダーの内容は一切含まれません。通信の目的と送信する内容は次のとおりです。

  • 設定値の確認（/api/ext/config）
    無料利用回数の制限が有効かどうかを確認します。送信するのは拡張機能の識別子のみで、本文はなく、ログインも必要ありません。ユーザーが検索ボタンを押したときに確認し、結果は5分間キャッシュするため、実際の通信はごくまれです。サイドパネルの起動、ログイン、検索条件の変更、日付の移動では通信しません。
  • アカウント連携（/api/ext/link/）
    送信するのは、拡張機能の識別子と使い捨ての照合用文字列のみです。
  • 利用回数の管理（/api/ext/quota/）
    送信するのは、連携用セッショントークン、予約ID、使い捨ての鍵のみです。
  • 連携の解除（/api/ext/auth/logout）
    送信するのは、連携用セッショントークンのみです。

このうち、アカウント連携と利用回数の管理にかかわる通信は、無料利用回数の制限がスキマのサーバー側で有効になっている場合にのみ発生します。制限が有効になっていない場合、これらの通信は発生しません。

スキマのサーバーが保存するのは、無料利用回数の制限が有効な場合に、週あたりの利用回数を管理するための記録だけです。カレンダーの内容は保存しません。

7. アクセストークンの扱い

Google Calendar APIへのアクセスに使用するアクセストークンは、拡張機能内のJavaScriptのメモリ上にのみ保持されます。

トークンの認証キャッシュ自体は、Chromeの chrome.identity 機構が管理しており、本拡張機能側で独自に永続化することはありません。サイドパネルを閉じると、拡張機能側で保持していたメモリ上の値は破棄されます。

なお、§5・§6 で述べたスキマとの連携用セッショントークンは、Googleのアクセストークンとはまったく別のものです。Googleのアクセストークンがスキマのサーバーへ送信されることはありません。

8. 第三者提供

取得した情報を第三者に販売・提供・共有することは一切ありません。

9. 広告・解析・トラッキング

本拡張機能は、広告配信、アクセス解析、行動トラッキングのいずれも行いません。

10. Cookie

本拡張機能はCookieを使用しません。

§6 に記載した sukimacalendar.com との通信でもCookieは送受信せず、連携用セッショントークンを Authorization ヘッダで送る方式を用いています。

11. 権限の取り消しとログアウト

本拡張機能にはログアウト機能があり、いつでもログアウトできます。

また、Googleアカウントの権限管理ページからも、本拡張機能へのアクセス権限をいつでも取り消すことができます。

https://myaccount.google.com/permissions

12. セキュリティ

Google Calendar APIとの通信はHTTPSで行われます。

本拡張機能は、閲覧中のWebページの内容を取得する権限を持たず、実際に取得も行いません。アクセス先は、Google Calendar API（googleapis.com）と、§6 に記載したスキマのサービス（sukimacalendar.com）に限定されており、いずれもHTTPSで通信します。

13. Google API Services User Data Policy

本拡張機能は、Google API Services User Data Policyに準拠して開発しています。

14. Limited Useへの準拠

本拡張機能によるGoogleユーザーデータの利用は、Limited Use requirementsに準拠しています。取得した情報は空き時間の計算・表示という本来の機能提供のためにのみ利用し、それ以外の目的（広告、AIモデルの学習等）には利用しません。

15. ポリシーの変更

本ポリシーの内容は、本拡張機能の仕様変更等に応じて、予告なく変更する場合があります。変更後の内容は本ページに掲載した時点で効力を持つものとします。
