スキマ Chrome拡張 - プライバシーポリシー

Privacy Policy for Chrome Extension

1. はじめに

本ページは、Chromeのサイドパネルで動作する拡張機能「スキマ」（以下「本拡張機能」）における情報の取り扱いについて説明するプライバシーポリシーです。

Web版「スキマ」（sukimacalendar.com）のプライバシーポリシーとは別に、本拡張機能専用のものとして本ページを設けています。Web版をご利用の場合は、Web版のプライバシーポリシー（/privacy）をご確認ください。

2. 取得する情報

本拡張機能は、ユーザーがGoogleアカウントでログインした際に、Googleカレンダーのカレンダー一覧情報と予定の日時情報のみを取得します。

メールアドレスその他の個人情報を取得することはありません。

3. Googleカレンダーから取得する情報

本拡張機能がGoogle Calendar APIから取得する情報は以下のとおりです。

  • カレンダー一覧：カレンダー名、カレンダーID、アクセス権限（オーナー／編集者／閲覧者）
  • 予定情報：開始日時、終了日時のみ

予定のタイトル、参加者、場所、詳細説明などの情報は、空き時間の計算には利用しません。

4. 情報の利用目的

取得した情報は、ユーザーが指定した期間における空き時間の計算と表示のためだけに利用します。

上記以外の目的には利用しません。

5. 情報の保存

本拡張機能は、取得したカレンダー情報を chrome.storage、localStorage、sessionStorage、IndexedDB のいずれにも保存しません。

取得した情報は拡張機能のサイドパネルを表示している間のみ、ブラウザのメモリ上で一時的に扱われ、サイドパネルを閉じるとその内容は破棄されます。

6. 外部送信

本拡張機能が通信を行う先は、Google Calendar API（googleapis.com）のみです。

開発者が運営する自社サーバーやデータベースへ、取得した情報を送信することはありません。

7. アクセストークンの扱い

Google Calendar APIへのアクセスに使用するアクセストークンは、拡張機能内のJavaScriptのメモリ上にのみ保持されます。

トークンの認証キャッシュ自体は、Chromeの chrome.identity 機構が管理しており、本拡張機能側で独自に永続化することはありません。サイドパネルを閉じると、拡張機能側で保持していたメモリ上の値は破棄されます。

8. 第三者提供

取得した情報を第三者に販売・提供・共有することは一切ありません。

9. 広告・解析・トラッキング

本拡張機能は、広告配信、アクセス解析、行動トラッキングのいずれも行いません。

10. Cookie

本拡張機能はCookieを使用しません。

11. 権限の取り消しとログアウト

本拡張機能にはログアウト機能があり、いつでもログアウトできます。

また、Googleアカウントの権限管理ページからも、本拡張機能へのアクセス権限をいつでも取り消すことができます。

https://myaccount.google.com/permissions

12. セキュリティ

Google Calendar APIとの通信はHTTPSで行われます。

本拡張機能は、閲覧中のWebページの内容を取得する権限を持たず、実際に取得も行いません。アクセス先はGoogle Calendar API（googleapis.com）に限定されています。

13. Google API Services User Data Policy

本拡張機能は、Google API Services User Data Policyに準拠して開発しています。

14. Limited Useへの準拠

本拡張機能によるGoogleユーザーデータの利用は、Limited Use requirementsに準拠しています。取得した情報は空き時間の計算・表示という本来の機能提供のためにのみ利用し、それ以外の目的（広告、AIモデルの学習等）には利用しません。

15. ポリシーの変更

本ポリシーの内容は、本拡張機能の仕様変更等に応じて、予告なく変更する場合があります。変更後の内容は本ページに掲載した時点で効力を持つものとします。
